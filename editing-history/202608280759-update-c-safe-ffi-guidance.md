# Update C-safe FFI guidance / 更新 C-safe FFI 指南

## 中文

- 删除继续保留 Rust-layout fallback 和 version probes 的过时维护说明。

## English

- Remove stale maintenance guidance that required Rust-layout fallbacks and version probes.
- State that dynamic boundaries use versioned C-safe protocols exclusively after Calcit 0.13.57.
