# Calcit 0.13.77 upgrade / 升级记录

Timestamp / 时间：2026-09-04T17:26:31Z

## 中文

- 将模块声明的 Calcit 工具链基线从 0.13.67 升级到已发布的 0.13.77。
- 将 `demo-server!` 的旧返回 schema 从 `Unit` 修正为 `FfiTask`，与 `serve-http!` 的公开契约及原有实现一致，保留调用方显式取消服务的句柄。
- 将 CI 与 README 的安装器引用从固定的 `setup-calcit@v1.3.0` 切换到维护中的 `setup-calcit@v1`，避免旧安装器下载其余工具时返回 HTTP 404。
- 保持模块版本 0.3.14、依赖图、C-safe buffer/async protocol v1、请求响应契约和取消语义不变。
- 使用发布版 Calcit 0.13.77 验证 Snapshot 规范化、静态质量门禁、Rust/ABI 构建和真实 HTTP 响应与任务取消流程。

## English

- Upgrade the declared Calcit toolchain baseline from 0.13.67 to the published 0.13.77 release.
- Correct the stale `demo-server!` return schema from `Unit` to `FfiTask`, matching the public `serve-http!` contract and original implementation while retaining the caller's handle for explicit cancellation.
- Move the CI and README installer reference from pinned `setup-calcit@v1.3.0` to the maintained `setup-calcit@v1` line, avoiding the old installer's HTTP 404 while fetching the remaining tool.
- Keep module version 0.3.14, the dependency graph, C-safe buffer/async protocol v1, request-response contracts, and cancellation semantics unchanged.
- Validate canonical Snapshot formatting, static quality gates, Rust/ABI builds, and the real HTTP response plus task-cancellation flow with released Calcit 0.13.77.
