# Release 0.3.16 / 发布 0.3.16

## English

- Release the Calcit 0.14.7 strict-mode migration.
- Keep heterogeneous HTTP request and response EDN values inside an explicit FFI boundary with zero unresolved type or unsafe-coerce debt.
- Type the real server smoke task lifecycle as `Option<FfiTask>`.

## 中文

- 发布 Calcit 0.14.7 严格模式迁移。
- 将异构 HTTP 请求与响应 EDN 值限制在明确的 FFI 边界内，未解决类型和 unsafe-coerce 债务均为零。
- 将真实服务器 smoke 测试的任务生命周期标注为 `Option<FfiTask>`。
