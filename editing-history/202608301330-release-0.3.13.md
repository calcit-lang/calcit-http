# Release 0.3.13 / 发布 0.3.13

## 中文

- 发布 `calcit-http` 0.3.13，要求 Calcit 0.13.64。
- 保持 `calcit_native_ffi 0.1.3`、C-safe async ABI、typed HTTP task capabilities 以及 response/cancellation 语义不变。
- 发布前继续以真实 HTTP response、cancel runtime smoke 与静态质量 baseline 验证兼容性。

## English

- Release `calcit-http` 0.3.13 with Calcit 0.13.64 required.
- Keep `calcit_native_ffi 0.1.3`, the C-safe async ABI, typed HTTP task capabilities, and response/cancellation semantics unchanged.
- Continue validating compatibility with real HTTP response and cancellation runtime smoke plus the static quality baseline.
