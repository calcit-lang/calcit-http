# 发布 0.3.11 / Release 0.3.11

- HTTP server 任务现在暴露类型化 `FfiTask`，业务代码通过 `.cancel` / `.cancel-with` 管理生命周期。
- response capability 通过 `FfiResponse.resolve` 完成，原始生命周期过程保留在内部适配层。
- 使用 Calcit 0.13.59 完成类型检查、文档检查以及真实 request/response/cancel 回归。

- HTTP server tasks now expose typed `FfiTask` values and use `.cancel` / `.cancel-with` for lifecycle control.
- Response capabilities resolve through `FfiResponse.resolve`; raw lifecycle procedures remain internal adapters.
- Validated types, docs, and real request/response/cancel behavior with Calcit 0.13.59.
