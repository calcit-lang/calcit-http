# 发布 0.3.10 / Release 0.3.10

## 中文

- 发布基于稳定 `calcit_native_ffi 0.1.3` 的可取消 HTTP request 背压。
- server cancel 可打断 queue backlog 等待，terminal 继续独立清理 response capabilities。

## English

- Release cancellable HTTP request backpressure based on stable `calcit_native_ffi 0.1.3`.
- Allow server cancellation to interrupt queue-backlog waiting while terminal publication independently cleans up response capabilities.
