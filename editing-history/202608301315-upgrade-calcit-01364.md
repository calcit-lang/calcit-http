# Calcit 0.13.64 upgrade / 升级记录

- 将模块要求的 Calcit 版本从 0.13.60 升级到 0.13.64。
- 保持 `calcit_native_ffi 0.1.3`、C-safe buffer/async protocol v1 和 exactly-once response capability 语义不变。
- 通过 Rust、Calcit quality baseline、真实 HTTP response 与 task cancellation 回归验证。
